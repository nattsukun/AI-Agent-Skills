# /vibe-ideate

**Phase:** DEFINE  
**Lead:** PO | **Support:** BA, UX

Turn a rough idea into a product brief with MVP boundary and success metrics.

Load skill: `vibecoding-squad-gsd`  
Playbook: `references/command-playbooks.md` → /vibe-ideate

**User prompt template:**

```text
/vibe-ideate

Idea: [what you want to build or achieve]
Context: [what exists today]
Users: [who benefits]
Constraints: [time, budget, tech, compliance]
```

**Output:** Product brief + DEFINE GSD card + handoff to /vibe-spec
